# Paulus — Home / Beranda

Kerjakan halaman Home RECLUB di folder ini. Buat file utama `home_page.dart` dan simpan komponen buatanmu di subfolder `widgets/`.

Target tugas: minimal 5 widget buatan sendiri. Contoh: search bar, filter kategori, kartu kegiatan, kartu klub, dan bagian kegiatan populer.

Jangan mengubah `main.dart` atau file fitur anggota lain tanpa koordinasi. Integrasi navigasi dilakukan bersama setelah halaman tersedia.

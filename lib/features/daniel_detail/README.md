# Daniel — Detail Klub / Kegiatan

Kerjakan halaman detail klub atau kegiatan di folder ini. Buat file utama `detail_page.dart` dan simpan komponen buatanmu di subfolder `widgets/`.

Target tugas: minimal 5 widget buatan sendiri. Contoh: header gambar, info kegiatan, chip kategori, daftar peserta, dan tombol ikut.

Jangan mengubah `main.dart` atau file fitur anggota lain tanpa koordinasi. Integrasi navigasi dilakukan bersama setelah halaman tersedia.

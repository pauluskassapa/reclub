# Joan — Profil / Riwayat Aktivitas

Kerjakan halaman profil dan riwayat aktivitas di folder ini. Buat file utama `profile_page.dart` dan simpan komponen buatanmu di subfolder `widgets/`.

Target tugas: minimal 5 widget buatan sendiri. Contoh: avatar, kartu informasi profil, menu edit profil, tab aktivitas, dan kartu riwayat.

Jangan mengubah `main.dart` atau file fitur anggota lain tanpa koordinasi. Integrasi navigasi dilakukan bersama setelah halaman tersedia.

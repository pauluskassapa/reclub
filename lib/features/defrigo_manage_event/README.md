# Defrigo — Buat / Kelola Kegiatan

Kerjakan halaman untuk membuat atau mengelola kegiatan di folder ini. Buat file utama `manage_event_page.dart` dan simpan komponen buatanmu di subfolder `widgets/`.

Target tugas: minimal 5 widget buatan sendiri. Contoh: input nama, input deskripsi, pemilih tanggal, pemilih lokasi, dan tombol simpan.

Jangan mengubah `main.dart` atau file fitur anggota lain tanpa koordinasi. Integrasi navigasi dilakukan bersama setelah halaman tersedia.
